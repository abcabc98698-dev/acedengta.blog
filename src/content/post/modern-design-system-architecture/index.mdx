静态截图的美感容易达成，而在面对真实业务场景、多端屏幕尺寸以及暗色模式切换时，依然能保持克制且一致的视觉秩序，才是设计系统的真正考验。

本文将深入拆解 Ace灯塔背后的设计系统实现：我们如何通过轻量级设计令牌（Design Tokens）、双重字体策略与微动效规范，构建出兼顾工程效率与活品质感的视觉底座。

## 1. 字体层级：双字体各司其职

在大多数 Web 项目中，团队往往采用单一无衬线字体，虽然安全，却缺少精神内核。我们在系统中确立了清晰的排版分工：

| 字体分类 | 角色定位 | 应用场景 |
|---------|---------|---------|
| Instrument Serif | 品牌表达与点睛 | 英雄标题、主章节标题、`.font-brand` 标识 |
| Inter | 易读性与功能支撑 | 正文段落、表单输入、按钮文本与说明标签 |

衬线体带来具有人文质感的思考深度，而无衬线体则保证在微小字号下的极佳辨识度。两者互不争抢，构建出张弛有度的视觉流。

```css
@theme {
  --font-brand: "Instrument Serif", Georgia, serif;
  --font-sans: "Inter", system-ui, sans-serif;
}
```

## 2. 严密的色彩哲学与暗色适配

整个界面依托三层色彩体系，避免了无节制的颜色膨胀：

- **主色（Primary）**：用于核心操作、重要链接与交互高亮，沉稳且有力量；
- **点睛色（Accent）**：微量用于徽章、特定状态与关键强调；
- **页面画布底色（Canvas）**：使用温暖柔和的浅色底色替代刺眼的纯白，配合经过对比度校验的暗色调，保证全天候的舒适阅读体验。

通过全局变量机制，系统在页面首次渲染前通过同步脚本读取用户偏好，杜绝暗色模式加载时的白屏闪烁（FOUC）。

## 3. 虚线边界与节奏结构

在布局隔断上，系统大量运用了细腻的虚线边框（Dashed Borders）替代生硬的实线。这种结构策略不仅有效区分了内容模块，还赋予页面一种类似于“工程图纸”或“航海日志”的精致工业美感。

## 结语

一个优秀的设计系统绝非死板的规范清单，而是一组精心推敲的约束与平衡。它让开发者在新增页面与内容时无需反复纠结间距与配色，让工程的创造力能够真正聚焦在内容与核心逻辑本身。
