对于追求高灵活度与网络分流精细控制的用户而言，基于开源内核的 **Clash Verge Rev** 是目前在 Windows 和 macOS 平台最受欢迎的客户端之一。

配合灯塔加速器的全链路 **IEPL 专线** 与 **VLESS 协议**，能够实现国内流量直连、国际流量毫秒级加速，互不干扰。

## 准备工作

在开始配置前，请确保您已具备：
1. **灯塔加速器有效账户与套餐**（新用户可前往[官方用户中心](https://sahude.gsyvipaff.com/#/?code=keqgvT5Y)完成开通）；
2. 电脑已下载安装最新版本的 Clash Verge Rev 客户端。

## 第一步：获取专属订阅链接

1. 登录灯塔加速器官方用户中心；
2. 在控制面板的“快速订阅”区域，找到 **Clash 订阅** 选项；
3. 点击“一键复制订阅地址”，将链接保存在剪贴板中。

## 第二步：在客户端中导入订阅

1. 打开 Clash Verge Rev 客户端，点击左侧导航栏的 **订阅（Profiles）**；
2. 在顶部输入框中粘贴刚才复制的灯塔专属订阅地址；
3. 点击右侧的 **导入（Import）** 按钮，系统将自动拉取最新的全节点配置列表；
4. 导入完成后，在订阅卡片上**单选激活**该配置，卡片边缘将亮起高亮标记。

## 第三步：选择代理模式与优质专线

进入客户端的 **代理（Proxies）** 界面：
- **模式建议选择：规则模式（Rule）**。在此模式下，百度、微信、淘宝等国内服务自动走本地直连，不消耗套餐流量；Google、GitHub、Netflix、ChatGPT 等国际业务自动经由灯塔 IEPL 专线加速。
- **节点选择建议**：
  - 日常网页浏览与 4K 视频：优先选择香港 01-10 或日本节点，物理时延极低（通常在 12-40ms 之间）；
  - TikTok 直播与电商：建议固定选择新加坡或美国原生专线节点；
  - 遇到节点波动时，可点击右下角“延迟测速”雷达按钮，客户端会自动测得当前可用节点的真实握手时延。

## 高阶技巧：开启系统代理与 TUN 模式

- 在 **设置（Settings）** 页面，打开 **系统代理（System Proxy）** 开关，即可开始全局科学浏览；
- 如需加速全系统命令行终端（Git、npm、Docker）或部分不走系统代理的海外桌面软件，可以在设置中开启 **TUN 模式（TUN Mode）**，客户端将接管整机网络流量，彻底免除端口配置烦恼。
