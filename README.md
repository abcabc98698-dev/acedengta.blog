# Ace灯塔 (AceDengta Blog)

> 数字化思考与现代技术实践官方平台。基于 Astro 6、Tailwind CSS v4 与 MDX 构建，采用零运行时优先与纯净架构标准。

---

## 🌟 核心特性

- **100% 纯净与自主独立**：剔除所有外部侵入式依赖与模板暗桩，代码完全自主可控。
- **极致性能（Lighthouse 95+）**：默认 Zero-JS 架构，毫秒级首屏加载响应。
- **全链路 SEO 优化**：
  - 自动生成标准绝对路径 Canonical URL
  - 完整 OpenGraph 与 Twitter Card 社交图谱
  - Schema.org (JSON-LD) 结构化数据
  - 自动生成 `robots.txt` 与 `sitemap-index.xml`
  - 规范化 RSS 订阅源 (`/rss.xml`)
- **设计令牌驱动（Design Tokens）**：基于现代 CSS 变量体系与 Instrument Serif + Inter 排版韵律。
- **暗色模式平滑切换**：原生客户端同步预读，彻底消除暗色加载时的白屏闪烁（FOUC）。

---

## 🛠 本地开发与构建

```bash
# 安装依赖
pnpm install

# 启动本地开发服务 (默认端口 5200)
pnpm dev

# 执行静态构建与类型检查
pnpm build

# 预览生产构建制品
pnpm preview
```
